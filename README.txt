Poodll Wordcards Module for Moodle
=============

Poodll WordCards is a flashcard-based vocabulary learning activity for Moodle. Teachers assign
words or phrases; students learn and review them through six practice activities (choose the
answer, type the answer, listen and type, listen and choose, say the words, and a space game),
with per-student progress tracked automatically across every instance of the activity.

Poodll Wordcards requires a Cloud Poodll API username and secret from https://poodll.com
See here: https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret

See README.md in this folder for the full documentation: features, installation, site settings,
the practice activities, Steps/Free mode and word pools.
