# Poodll WordCards for Moodle

**A flashcard-based vocabulary learning activity for Moodle, with automatic AI-assisted card
creation and per-student progress tracking.**

The teacher assigns a set of words or phrases (terms and definitions). Students learn and review
them through six different practice activities, and Poodll WordCards tracks each learner's own
pool of new, review and self-claimed words across every instance of the activity in the course.

## Requirements

| | |
|---|---|
| Moodle | 4.3 or later (`$plugin->requires = 2023100900`)|
| PHP | 8.1+ |
| Database | MySQL / MariaDB / PostgreSQL |
| Cloud Poodll account | **Required.** An API user and secret from https://poodll.com |

WordCards relies on the Cloud Poodll service for text to speech, speech recognition, AI
dictionary lookups and AI image generation. Without API credentials the activity will not
function. See [Cloud Poodll API secret](https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret)
for how to obtain them.

## Installation

1. Copy the plugin folder to `mod/wordcards` in your Moodle code root (on Moodle 5.0+ this is
   `public/mod/wordcards`).
2. Visit **Site administration → Notifications** and complete the upgrade.
3. Enter your Cloud Poodll API user and secret at
   **Site administration → Plugins → Activity modules → Poodll WordCards**.

## Site configuration

Settings live under **Site administration → Plugins → Activity modules → Poodll WordCards**:

- **API user / API secret** Without these the plugin will not function.
- **AWS region**  The AWS region processing and data storage take place in, - - **Cloud Poodll server** The default is fine. Users with AWS region Ningxia in China should use cloud.poodll.cn
- Default journey mode (Steps / Free / Steps then Free), default card front/back content,
  whether cards can be flipped, and whether students see a language chooser.


## Building a word set

Words (terms and definitions) can be added to an activity three ways:

- **Manually**, one at a time, with a definition, image, and audio (recorded, uploaded, or
  generated by text to speech).
- **Imported from a CSV file**.
- **Word Wizard** — enter a list of words and it fetches definitions automatically via an
  AI-powered dictionary; a companion **Image Wizard** can bulk-generate an image for every term
  that doesn't already have one.

## The six practice activities

| Activity | What the student does |
|---|---|
| **Choose the Answer** | Pick the correct definition/term from options. |
| **Type the Answer** | Type the matching term or definition. |
| **Listen and Type** | Listen to the audio and type what they hear. |
| **Listen and Choose** | Listen to the audio and choose the matching card. |
| **Say the Words** | Say the word or phrase aloud; graded by speech recognition. Requires voice transcription AI, which may not be available for every language. |
| **Space Game** | An arcade-style game built from the word set. |

Each activity has a review variant, drawing on words already studied rather than new ones. A
**Words Preview** step lets students look over a set of cards before practicing.

## Steps mode and Free mode

- **Steps mode** — the teacher defines up to 5 steps; each step picks an activity type, a word
  pool, and how many terms to practice. All steps are auto-graded.
- **Free mode** — the student chooses their own practice activity and word pool (new, review, or
  My Words) and practices at their own pace.
- **Steps then Free** — a hybrid: the steps run first, then the activity opens into free
  practice.

## Word pools and self-claiming

Each learner has three word pools: **new** words not yet studied, **review** words the activity
has decided need reinforcing, and **My Words** — a personal list a student can add to (and
remove from) themselves. Students can also **self-claim** a word as already known, outside the
normal review cycle.

## Reports and completion

Teachers get per-student and course-level reports on words learned, review progress and
self-claimed words. Activity completion can require a target number of words learned.

Over 50 speech recognition / TTS locales are supported, including multiple variants of English,
Spanish, French, German, Portuguese, Chinese, Japanese, Korean, Arabic, Hindi and many more —
though the Say the Words activity needs voice transcription support for the language in
question.

## Mobile support

Poodll WordCards is supported in the Moodle mobile app via `db/mobile.php`.

## Privacy

WordCards stores personal data: word-pool progress, attempts, session data, recordings and any
audio/images uploaded. Recordings are stored via Cloud Poodll (AWS S3), and the Moodle user id
appears in recording URLs. The plugin implements the Moodle Privacy API for export and deletion.
